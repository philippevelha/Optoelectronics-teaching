9.1 Key relations

Load line. A photodiode reverse biased by \(V_r\) through a load \(R_L\) (slide 75) must satisfy both its own I–V curve and Kirchhoff’s law for the loop (slide 76):

\[ I=-\frac{V+V_r}{R_L}\quad\text{(load line)},\qquad I=I_o\left[e^{eV/\eta k_BT}-1\right]-I_{ph}\quad\text{(photodiode)}. \]

The operating point P is their intersection. As long as P stays in the reverse-bias region, \(I\approx-I_{ph}\) and the output voltage \(|I|R_L\) is linear in the power. When \(I_{ph}R_L\) approaches \(V_r\), the diode is pushed towards forward bias and the response saturates.

Transimpedance amplifier (TIA). An op-amp with a feedback resistor \(R_F\) holds the photodiode at virtual ground (or at \(-V_r\)) and converts the current into \(V_\text{out}=-I_{ph}R_F\) (slide 77). The diode never sees a voltage swing, so the response is linear, and the bandwidth is no longer \(1/2\pi R_FC_d\) (see the panel).

Equivalent circuit and bandwidth. A real photodiode is a current source \(I_{ph}\) in parallel with the ideal diode, the depletion plus package capacitance \(C_t\) and a shunt resistance \(R_p\), followed by a series resistance \(R_s\) (slides 78–79). For signals faster than the drift and diffusion times are negligible, the bandwidth is set by the \(RC\) time constant (slide 80):

\[ f_c=\frac{1}{2\pi R_\text{eq}C_t}\approx\frac{1}{2\pi(R_s+R_L)C_t}\approx\frac{1}{2\pi R_LC_t},\qquad R_\text{eq}=(R_s+R_L)\parallel R_p . \]

Rise and fall times. For a step of light, an RC circuit charges as \(1-e^{-t/\tau}\) with \(\tau=(R_s+R_L)C_t\). The 10–90 % rise time and the 90–10 % fall time are (slides 83–84)

\[ \tau_r=\tau_F=2.2\,\tau,\qquad f_c=\frac{1}{2\pi\tau}=\frac{0.35}{\tau_r}=\frac{350\ \text{MHz}}{\tau_r\ [\text{ns}]}. \]

When the \(RC\) constant is small, the pulse shows the device physics instead (slide 85): a fast drift component from carriers generated in the depletion region and a slow diffusion tail from carriers generated in the neutral regions (Chapter 5).

With the values of slide 76 (\(V_r=6\) V, \(R_L=1\) MΩ, \(I_{ph}\approx2.5\) µA, i.e. 5 µW at 0.5 A/W) the operating point sits at \(V'\approx-3.5\) V. 9.3 Live panel: pulse response, RC versus device physics (slides 82–85)

Show the Python 
viewof pr = Inputs.form({
  C: Inputs.range([0.1, 100], {value: 5, step: 0.1, label: "total capacitance C_t (pF)"}),
  RL: Inputs.range([10, 10000], {value: 50, step: 10, label: "R_s + R_L (Ω)"}),
  ttr: Inputs.range([0.01, 5], {value: 0.2, step: 0.01, label: "drift (transit) time (ns)"}),
  fd: Inputs.range([0, 0.8], {value: 0.2, step: 0.01, label: "fraction of carriers generated in neutral regions"}),
  td: Inputs.range([0.1, 50], {value: 5, step: 0.1, label: "diffusion time constant (ns)"}),
  Tp: Inputs.range([1, 200], {value: 30, step: 1, label: "light pulse length (ns)"})
})
Show the Python 
prOut = {
  const tau = pr.RL * pr.C * 1e-3, tEnd = pr.Tp + 6 * Math.max(tau, pr.td * (pr.fd > 0), pr.ttr) + 5, N = 6000, dt = tEnd / N;
  let idrift = 0, idiff = 0, v = 0; const pts = [];
  // intrinsic current: drift part follows the light with a first-order lag ≈ t_tr/2.2; diffusion part with time constant t_d
  // exact exponential updates (stable for any time step)
  const tdr = Math.max(pr.ttr / 2.2, 1e-4), kdr = 1 - Math.exp(-dt / tdr), kdf = 1 - Math.exp(-dt / pr.td), kv = 1 - Math.exp(-dt / tau);
  for (let i = 0; i <= N; i++) {
    const t = i * dt, Pin = (t >= 0 && t < pr.Tp) ? 1 : 0;
    idrift += kdr * ((1 - pr.fd) * Pin - idrift); idiff += kdf * (pr.fd * Pin - idiff);
    v += kv * (idrift + idiff - v);
    pts.push({t, P: Pin, v});
  }
  const vmax = d3.max(pts, d => d.v), on = pts.filter(d => d.t < pr.Tp), off = pts.filter(d => d.t >= pr.Tp);
  const cross = (arr, lvl, up) => (arr.find(d => up ? d.v >= lvl * vmax : d.v <= lvl * vmax) || {t: NaN}).t;
  const tr = cross(on, 0.9, true) - cross(on, 0.1, true), tf = cross(off, 0.1, false) - cross(off, 0.9, false);
  return {pts, tau, tr, tf};
}

With 5 pF on 50 Ω the RC constant is 0.25 ns and the pulse shows the device: a fast edge (drift) followed by a slow tail (diffusion), the shape of slide 85. Switch the load to 10 kΩ: the pulse becomes a clean RC exponential with \(\tau_r=2.2RC\), and the diffusion tail is hidden. Set the neutral-region fraction to zero: the tail disappears; this is what a pin with a thin p⁺ layer and a fully depleted i-layer achieves.

9.4 Live panel: why a transimpedance amplifier (slide 77)

For a TIA with an op-amp of gain–bandwidth product GBW and a diode capacitance \(C_d\), the closed loop is a second-order system; with the feedback capacitance chosen for a flat (Butterworth) response its bandwidth is about \(f_{3dB}\approx\sqrt{\text{GBW}/(2\pi R_FC_d)}\). The input-referred noise of \(R_F\) is \(\sqrt{4k_BT/R_F}\), as for a load resistor of the same value (Chapter 10).

Show the Python 
viewof tia = Inputs.form({
  lRF: Inputs.range([2, 8], {value: 5, step: 0.05, label: "log₁₀ feedback (or load) resistance R (Ω)"}),
  Cd: Inputs.range([0.1, 100], {value: 10, step: 0.1, label: "photodiode + input capacitance C_d (pF)"}),
  gbw: Inputs.range([1, 10000], {value: 100, step: 1, label: "op-amp gain–bandwidth product (MHz)"})
})
Show the Python 
tiaOut = {
  const R = 10 ** tia.lRF, C = tia.Cd * 1e-12, fRL = 1 / (2 * Math.PI * R * C), fT = Math.sqrt(tia.gbw * 1e6 / (2 * Math.PI * R * C));
  const sweep = d3.range(0, 121).map(i => { const r = 10 ** (2 + 6 * i / 120); return {R: r, load: 1 / (2 * Math.PI * r * C), tia: Math.min(Math.sqrt(tia.gbw * 1e6 / (2 * Math.PI * r * C)), tia.gbw * 1e6)}; });
  return {R, fRL, fT: Math.min(fT, tia.gbw * 1e6), sweep, noise: Math.sqrt(4 * 1.380649e-23 * 300 / R)};
}
Plot.plot({

  marks: [Plot.line(tiaOut.sweep, {x: "R", y: "load", stroke: () => "load resistor R_L = R", strokeWidth: 2}),
          Plot.line(tiaOut.sweep, {x: "R", y: "tia", stroke: () => "TIA with R_F = R", strokeWidth: 2}), Plot.ruleX([tiaOut.R], {stroke: "#52514e", strokeDasharray: "4,3"})]
})

TipGoing further
  • TIA noise is not just \(R_F\). The op-amp voltage noise \(e_n\) appears across \(C_d\) as a current noise \(e_n\cdot2\pi fC_d\) that grows with frequency (“\(e_nC\) noise”). It dominates high-speed receivers. Compute the integrated noise current of a 10 GHz TIA with \(e_n=1\) nV/√Hz and \(C_d=0.2\) pF, and compare with \(\sqrt{4k_BTB/R_F}\) for \(R_F=500\) Ω.
  • Bootstrapping and cascodes. Reduce the effective \(C_d\) by driving the photodiode cathode with a copy of the anode voltage. How much faster does a 1 nF photodiode become?
  • Rise time of cascaded stages. For Gaussian-like responses, rise times add in quadrature, \(\tau_r^2=\sum\tau_{r,i}^2\). Use it to budget a fiber link (Ch. 2): transmitter, fiber dispersion, photodiode, TIA.
  • The commercial photoreceiver of slide 81 puts the APD, the TIA and a TEC with its temperature sensor in one package. Why must the APD be temperature controlled (Chapter 6), and why are the TIA and APD inside the same can?

## Key relations

Kirchhoff's law for the loop (slide 76):

$$
I=-\frac{V+V_r}{R_L}\quad\text{(load line)},\qquad I=I_o\left[e^{eV/\eta k_BT}-1\right]-I_{ph}\quad\text{(photodiode)}.
$$

voltage $|I|R_L$ is linear in the power. When $I_{ph}R_L$ approaches $V_r$, the diode is pushed towards forward bias and the
response **saturates**.

**Transimpedance amplifier (TIA).** An op-amp with a feedback resistor $R_F$ holds the photodiode at virtual ground (or at $-V_r$)
and converts the current into $V_\text{out}=-I_{ph}R_F$ (slide 77). The diode never sees a voltage swing, so the response is linear,
and the bandwidth is no longer $1/2\pi R_FC_d$ (see the panel).

depletion plus package capacitance $C_t$ and a shunt resistance $R_p$, followed by a series resistance $R_s$ (slides 78–79). For
signals faster than the drift and diffusion times are negligible, the bandwidth is set by the $RC$ time constant (slide 80):

$$
f_c=\frac{1}{2\pi R_\text{eq}C_t}\approx\frac{1}{2\pi(R_s+R_L)C_t}\approx\frac{1}{2\pi R_LC_t},\qquad
R_\text{eq}=(R_s+R_L)\parallel R_p .
$$

**Rise and fall times.** For a step of light, an RC circuit charges as $1-e^{-t/\tau}$ with $\tau=(R_s+R_L)C_t$. The 10–90 % rise time
and the 90–10 % fall time are (slides 83–84)

$$
\tau_r=\tau_F=2.2\,\tau,\qquad f_c=\frac{1}{2\pi\tau}=\frac{0.35}{\tau_r}=\frac{350\ \text{MHz}}{\tau_r\ [\text{ns}]}.
$$

When the $RC$ constant is small, the pulse shows the device physics instead (slide 85): a fast drift component from carriers
generated in the depletion region and a slow **diffusion tail** from carriers generated in the neutral regions (@sec-pin).

## Live panel: pulse response, RC versus device physics (slides 82–85)

```{ojs}
//| echo: false
viewof pr = Inputs.form({
  C: Inputs.range([0.1, 100], {value: 5, step: 0.1, label: "total capacitance C_t (pF)"}),
  RL: Inputs.range([10, 10000], {value: 50, step: 10, label: "R_s + R_L (Ω)"}),
  ttr: Inputs.range([0.01, 5], {value: 0.2, step: 0.01, label: "drift (transit) time (ns)"}),
  fd: Inputs.range([0, 0.8], {value: 0.2, step: 0.01, label: "fraction of carriers generated in neutral regions"}),
  td: Inputs.range([0.1, 50], {value: 5, step: 0.1, label: "diffusion time constant (ns)"}),
  Tp: Inputs.range([1, 200], {value: 30, step: 1, label: "light pulse length (ns)"})
})
```

```{ojs}
//| echo: false
prOut = {
  const tau = pr.RL * pr.C * 1e-3, tEnd = pr.Tp + 6 * Math.max(tau, pr.td * (pr.fd > 0), pr.ttr) + 5, N = 6000, dt = tEnd / N;
  let idrift = 0, idiff = 0, v = 0; const pts = [];
  // intrinsic current: drift part follows the light with a first-order lag ≈ t_tr/2.2; diffusion part with time constant t_d
  // exact exponential updates (stable for any time step)
  const tdr = Math.max(pr.ttr / 2.2, 1e-4), kdr = 1 - Math.exp(-dt / tdr), kdf = 1 - Math.exp(-dt / pr.td), kv = 1 - Math.exp(-dt / tau);
  for (let i = 0; i <= N; i++) {
    const t = i * dt, Pin = (t >= 0 && t < pr.Tp) ? 1 : 0;
    idrift += kdr * ((1 - pr.fd) * Pin - idrift); idiff += kdf * (pr.fd * Pin - idiff);
    v += kv * (idrift + idiff - v);
    pts.push({t, P: Pin, v});
  }
  const vmax = d3.max(pts, d => d.v), on = pts.filter(d => d.t < pr.Tp), off = pts.filter(d => d.t >= pr.Tp);
  const cross = (arr, lvl, up) => (arr.find(d => up ? d.v >= lvl * vmax : d.v <= lvl * vmax) || {t: NaN}).t;
  const tr = cross(on, 0.9, true) - cross(on, 0.1, true), tf = cross(off, 0.1, false) - cross(off, 0.9, false);
  return {pts, tau, tr, tf};
}
Plot.plot({
  width: Math.min(width, 1050), height: 260, x: {label: "time (ns)"}, y: {label: "normalised", grid: true},
  color: {legend: true, domain: ["light pulse", "V_out"], range: ["#c3c2b7", "#2a78d6"]},
  marks: [Plot.line(prOut.pts, {x: "t", y: "P", stroke: () => "light pulse", strokeWidth: 1.5}),
          Plot.line(prOut.pts, {x: "t", y: "v", stroke: () => "V_out", strokeWidth: 2})]
})
```

```{ojs}
measured: rise time τ<sub>r</sub> = <b>${prOut.tr.toPrecision(3)} ns</b>, fall time τ<sub>F</sub> = <b>${prOut.tf.toPrecision(3)} ns</b> ·
0.35/τ<sub>r</sub> = ${(350 / prOut.tr).toPrecision(3)} MHz ${Math.abs(prOut.tr / (2.2 * prOut.tau) - 1) < 0.1 ? "(RC-limited: matches 2.2τ)" : "(not RC-limited: device physics shows)"}</div>`
```

With 5 pF on 50 Ω the RC constant is 0.25 ns and the pulse shows the device: a fast edge (drift) followed by a slow tail
(diffusion), the shape of slide 85. Switch the load to 10 kΩ: the pulse becomes a clean RC exponential with $\tau_r=2.2RC$, and
the diffusion tail is hidden. Set the neutral-region fraction to zero: the tail disappears; this is what a pin with a thin p⁺ layer
and a fully depleted i-layer achieves.

## Live panel: why a transimpedance amplifier (slide 77)

For a TIA with an op-amp of gain–bandwidth product GBW and a diode capacitance $C_d$, the closed loop is a second-order system; with
the feedback capacitance chosen for a flat (Butterworth) response its bandwidth is about $f_{3dB}\approx\sqrt{\text{GBW}/(2\pi R_FC_d)}$.
The input-referred noise of $R_F$ is $\sqrt{4k_BT/R_F}$, as for a load resistor of the same value (@sec-noise).

```{ojs}
//| echo: false

  lRF: Inputs.range([2, 8], {value: 5, step: 0.05, label: "log₁₀ feedback (or load) resistance R (Ω)"}),
  Cd: Inputs.range([0.1, 100], {value: 10, step: 0.1, label: "photodiode + input capacitance C_d (pF)"}),
  gbw: Inputs.range([1, 10000], {value: 100, step: 1, label: "op-amp gain–bandwidth product (MHz)"})
})
```

```{ojs}

  const sweep = d3.range(0, 121).map(i => { const r = 10 ** (2 + 6 * i / 120); return {R: r, load: 1 / (2 * Math.PI * r * C), tia: Math.min(Math.sqrt(tia.gbw * 1e6 / (2 * Math.PI * r * C)), tia.gbw * 1e6)}; });
```

## Going further
- **TIA noise is not just $R_F$.** The op-amp voltage noise $e_n$ appears across $C_d$ as a current noise $e_n\cdot2\pi fC_d$ that grows
  with frequency ("$e_nC$ noise"). It dominates high-speed receivers. Compute the integrated noise current of a 10 GHz TIA with
  $e_n=1$ nV/√Hz and $C_d=0.2$ pF, and compare with $\sqrt{4k_BTB/R_F}$ for $R_F=500$ Ω.
- **Bootstrapping and cascodes.** Reduce the effective $C_d$ by driving the photodiode cathode with a copy of the anode voltage. How much
  faster does a 1 nF photodiode become?
- **Rise time of cascaded stages.** For Gaussian-like responses, rise times add in quadrature, $\tau_r^2=\sum\tau_{r,i}^2$. Use it to budget a
  fiber link (Ch. 2): transmitter, fiber dispersion, photodiode, TIA.
- **The commercial photoreceiver** of slide 81 puts the APD, the TIA and a TEC with its temperature sensor in one package. Why must the
  APD be temperature controlled (@sec-apd), and why are the TIA and APD inside the same can?
