6.1 Key relations

In an APD a primary photocarrier is accelerated by a field of several 10⁵ V/cm until it gains enough kinetic energy (more than about \(\frac32E_g\)) to excite a valence electron across the gap: impact ionisation (slide 45). Each ionisation creates a new pair, which is itself accelerated: an avalanche. The multiplication is (slide 46)

\[ M=\frac{I_{ph}}{I_{pho}},\qquad \mathcal R_{APD}=M\mathcal R_{M=1},\qquad M\approx\frac{1}{1-(V_r/V_{br})^m}\ \text{(empirical, } m\approx3\text{–}6). \]

The ionisation coefficient α is the number of ionisations per unit distance. It rises steeply with the field (Chynoweth’s law, slide 50), and electrons and holes have different coefficients, with the ratio \(k\):

\[ \alpha_e=A\exp(-B/E),\qquad k=\frac{\alpha_h}{\alpha_e}. \]

For electrons injected into a uniform avalanche region of width \(w\) (slide 51):

\[ M_e=\exp(\alpha_ew)\ \ (\text{electrons only, }k=0),\qquad M=\frac{1-k}{\exp[-(1-k)\alpha_ew]-k}\ \ (\text{both carriers}). \]

With \(k=0\) the gain grows smoothly with the field. With \(k>0\) the holes created by the electrons travel backwards and ionise too: a feedback loop. When \(\exp[-(1-k)\alpha_ew]=k\) the denominator vanishes and the current runs away: avalanche breakdown. A good APD material has \(k\ll1\) (Si: \(k\approx0.02\)–\(0.1\)) and the avalanche must be started by the carrier with the larger coefficient. The same \(k\) also sets the noise (Chapter 11).

Practical structures separate the two jobs. The Si reach-through APD (\(n^+p\pi p^+\), slide 44) absorbs in a wide, low-field π region and multiplies in a thin, high-field \(pn^+\) region. The InGaAs/InP SAM APD (slides 52–54) absorbs in InGaAs (1.55 µm) and multiplies in InP, where the field is high but the gap wide enough to avoid tunnelling; a graded InGaAsP layer (SAGM) removes the valence-band step \(\Delta E_v\) that would trap the holes at the heterointerface (slide 53).

avOut = {
  const w = av.w * 1e-4, gain = (E) => {
    const ae = chynoweth(E, av.mat, "e"), ah = chynoweth(E, av.mat, "h");
    const [a1, a2] = av.inj === "electrons" ? [ae, ah] : [ah, ae];
    return {ae, ah, M: apdGainUniform(a1, a2 / a1, w), M1: Math.exp(a1 * w)};
  };
  const pts = [];
  for (let i = 0; i <= 600; i++) {
    const E = 2e5 + 6e5 * i / 600, g = gain(E);
    if (isFinite(g.M) && g.M < 1e4) pts.push({E: E / 1e5, M: g.M, c: "both carriers ionise"});
    if (g.M1 < 1e4) pts.push({E: E / 1e5, M: g.M1, c: "injected carrier only"});
  }
  let Ebr = NaN; for (let i = 0; i <= 6000; i++) { const E = 2e5 + 6e5 * i / 6000; if (!isFinite(gain(E).M)) { Ebr = E; break; } }
  return {pts, cur: gain(av.E * 1e5), Ebr};
}

6.4 Live panel: why APDs need temperature control (slides 47, 55, 81)

Phonon scattering increases with temperature, so a carrier needs a higher field to reach the ionisation energy: the breakdown voltage rises by roughly 0.1–0.2 %/K in Si (slide 47 shows three temperatures). Using the empirical Miller law:

Show the Python 
viewof ml = Inputs.form({
  Vbr: Inputs.range([20, 400], {value: 160, step: 1, label: "breakdown voltage at 20 °C, V_br (V)"}),
  m: Inputs.range([1, 8], {value: 3, step: 0.1, label: "Miller exponent m"}),
  tc: Inputs.range([0, 0.4], {value: 0.15, step: 0.01, label: "temperature coefficient of V_br (%/K)"}),
  Vr: Inputs.range([20, 400], {value: 150, step: 0.5, label: "operating bias V_r (V)"})
})
Show the Python 
mlOut = {
  const temps = [-20, 20, 60], pts = [], cur = [];
  for (const T of temps) {
    const Vb = ml.Vbr * (1 + ml.tc / 100 * (T - 20));
    for (let i = 0; i <= 400; i++) { const V = 0.6 * ml.Vbr + 0.45 * ml.Vbr * i / 400; if (V < Vb) { const M = 1 / (1 - (V / Vb) ** ml.m); if (M < 500) pts.push({V, M, T: `${T} °C`}); } }
    cur.push({T, M: ml.Vr < Vb ? 1 / (1 - (ml.Vr / Vb) ** ml.m) : Infinity});
  }
  return {pts, cur};
}

html`<div class="result-box">at V<sub>r</sub> = ${ml.Vr} V: ${mlOut.cur.map(c => html`M(${c.T} °C) = <b>${isFinite(c.M) ? c.M.toFixed(1) : "breakdown"}</b> · `)}

At high gain a 1 K drift changes \(M\) by several percent. Commercial APD receivers therefore either stabilise the temperature with a thermoelectric cooler and sensor (the Voxtel module of slide 81) or adjust the bias with temperature.

TipGoing further
  • Non-uniform fields. Real avalanche regions have a triangular or trapezoidal field. Use dl.apd_gain_profile(x, αe(x), αh(x)), which integrates McIntyre’s general expression, for a p⁺n junction with a linear field and compare with a uniform field of the same peak value. Which carries more gain, the peak or the average?
  • Dead space. A carrier must travel a minimum distance \(d=E_i/eE\) before it can ionise again. In thin (≲ 100 nm) multiplication layers this makes the ionisation positions less random, which lowers the excess noise below McIntyre’s prediction: the basis of thin InAlAs and AlInAsSb APDs.
  • Geiger mode and SPADs. Biased above breakdown, an APD stays quiescent until a single carrier triggers a self-sustaining avalanche, which a quenching resistor stops: a single-photon avalanche diode. Count the photons, not the current. Photon-detection efficiency, dark-count rate, dead time and after-pulsing replace QE, dark current and bandwidth. SPAD arrays are the receivers of automotive lidar and of quantum-key-distribution links.
  • The superlattice APD (slide 60): at each conduction-band step \(\Delta E_c\) the electron gains energy abruptly, while holes see a smaller \(\Delta E_v\). This “staircase” enhances \(\alpha_e\) and lowers \(k\) artificially. Why is the valence-band step a problem?

## Live panel: why APDs need temperature control (slides 47, 55, 81)

Phonon scattering increases with temperature, so a carrier needs a higher field to reach the ionisation energy: the breakdown
voltage rises by roughly 0.1–0.2 %/K in Si (slide 47 shows three temperatures). Using the empirical Miller law:

## Going further
- **Non-uniform fields.** Real avalanche regions have a triangular or trapezoidal field. Use `dl.apd_gain_profile(x, αe(x), αh(x))`,
  which integrates McIntyre's general expression, for a p⁺n junction with a linear field and compare with a uniform field of the
  same peak value. Which carries more gain, the peak or the average?
- **Dead space.** A carrier must travel a minimum distance $d=E_i/eE$ before it can ionise again. In thin (≲ 100 nm) multiplication
  layers this makes the ionisation positions less random, which lowers the excess noise below McIntyre's prediction: the basis of
  thin InAlAs and AlInAsSb APDs.
- **Geiger mode and SPADs.** Biased *above* breakdown, an APD stays quiescent until a single carrier triggers a self-sustaining avalanche,
  which a quenching resistor stops: a **single-photon avalanche diode**. Count the photons, not the current. Photon-detection efficiency,
  dark-count rate, dead time and after-pulsing replace QE, dark current and bandwidth. SPAD arrays are the receivers of automotive
  lidar and of quantum-key-distribution links.
- **The superlattice APD** (slide 60): at each conduction-band step $\Delta E_c$ the electron gains energy abruptly, while holes see a
  smaller $\Delta E_v$. This "staircase" enhances $\alpha_e$ and lowers $k$ artificially. Why is the valence-band step a problem?
:::
