7.1 Key relations

Transverse modes (slide 75). Real mirrors are curved and finite, so the field that reproduces itself after a round trip is not a plane wave but a Gaussian beam (Ch. 1) multiplied by Hermite polynomials. The TEM\(_{mn}\) mode has \(m\) nodes along \(x\) and \(n\) along \(y\):

\[ E_{mn}(x,y)\propto H_m\!\left(\frac{\sqrt2x}{w}\right)H_n\!\left(\frac{\sqrt2y}{w}\right)\exp\!\left(-\frac{x^2+y^2}{w^2}\right). \]

TEM\(_{00}\) is the Gaussian beam with the smallest divergence; most lasers are designed to emit only this mode.

Line broadening (slides 76–83). An emitting transition is never infinitely sharp.

  • Homogeneous broadening affects all atoms in the same way: lifetime (natural) broadening, collisions in a gas, phonon collisions in a crystal. A field that decays as \(E_0e^{-t/2\tau_2}\cos\omega_0t\) has a Lorentzian spectrum (slides 77–78), \[g_L(\nu)=\frac{\gamma/\pi}{(\nu-\nu_0)^2+\gamma^2},\qquad \Delta\nu_\text{FWHM}=2\gamma=\frac{1}{2\pi\tau_2}.\]
  • Inhomogeneous broadening gives different atoms different centre frequencies: Doppler shifts in a gas, random local fields in a glass. The line is the envelope of many narrow lines, usually a Gaussian (slides 79–80), \[g_G(\nu)=\frac{1}{\sqrt\pi\,\Gamma}\exp\!\left[-\frac{(\nu-\nu_0)^2}{\Gamma^2}\right],\qquad \Delta\nu_\text{FWHM}=2\Gamma\sqrt{\ln2}.\]

When both act, the line is their convolution, the Voigt profile.

WarningLifetime broadening on slide 78

Slide 78 writes “\(1/\gamma=\tau_2\)” with \(\Delta\nu_\text{FWHM}=2\gamma\). For the field \(E_0e^{-t/2\tau_2}\cos\omega_0t\) written on the same slide, the Fourier transform gives a Lorentzian with \(\Delta\nu_\text{FWHM}=1/(2\pi\tau_2)\), that is \(\gamma=1/(4\pi\tau_2)\). The statement \(1/\gamma=\tau_2\) holds for the angular half width when the field (not the intensity) decays with \(\tau_2\). The factor \(4\pi\) matters: a 100 ns Ne level has a natural width of 1.6 MHz, not 20 MHz. Slide 80 also writes the normalisation as \(\int g_L\,d\nu=1\) under the Gaussian; it should read \(g_G\).

tmOut = {
  const H = (k, x) => { let h0 = 1, h1 = 2*x; if (k === 0) return h0; for (let i = 1; i < k; i++) { const h2 = 2*x*h1 - 2*i*h0; h0 = h1; h1 = h2; } return h1; };
  const N = 121, ext = 3.2, v = new Float64Array(N*N);
  for (let j = 0; j < N; j++) for (let i = 0; i < N; i++) {
    const x = -ext + 2*ext*i/(N - 1), y = -ext + 2*ext*j/(N - 1), g = Math.exp(-(x*x + y*y));
    const a = H(tm.m, Math.SQRT2*x)*H(tm.n, Math.SQRT2*y)*g, b = H(tm.n, Math.SQRT2*x)*H(tm.m, Math.SQRT2*y)*g;
    v[j*N + i] = tm.donut ? a*a + b*b : a*a;
  }
  const mx = d3.max(v); for (let k = 0; k < v.length; k++) v[k] /= mx;
  return {v, N, ext};
}

Each transverse mode \((m,n)\) has its own set of longitudinal resonances, shifted from those of TEM\(_{00}\) by the Gouy phase. A laser that oscillates on several transverse modes therefore emits extra frequencies and a larger, irregular beam. The frequencies and the mode size follow from the mirror curvatures: see Going further: optical resonators. An aperture inside the cavity (or, in a laser diode, a narrow stripe, Chapter 10) adds loss to the wider high-order modes and keeps only TEM\(_{00}\).

Show the Python 
lsOut = {
  const N = 2001, span = 12, dx = 2*span/(N - 1), xs = d3.range(N).map(i => -span + i*dx);
  const gam = Math.max(ls.fL, 1e-3)/2, G = Math.max(ls.fG, 1e-3)/(2*Math.sqrt(Math.LN2));
  const L = xs.map(x => (gam/Math.PI)/(x*x + gam*gam)), Ga = xs.map(x => Math.exp(-(x*x)/(G*G))/(Math.sqrt(Math.PI)*G));
  const V = xs.map((x, i) => { let s = 0; for (let k = 0; k < N; k += 2) s += Ga[k]*(gam/Math.PI)/((x - xs[k])**2 + gam*gam); return s*2*dx; });
  const fwhm = arr => { const m = d3.max(arr), idx = arr.map((v, i) => v >= m/2 ? i : -1).filter(i => i >= 0); return (idx[idx.length - 1] - idx[0])*dx; };
  const data = xs.flatMap((x, i) => [{x, y: L[i], who: "Lorentzian"}, {x, y: Ga[i], who: "Gaussian"}, {x, y: V[i], who: "Voigt (convolution)"}]);
  return {data, fV: fwhm(V), approx: 0.5346*ls.fL + Math.sqrt(0.2166*ls.fL**2 + ls.fG**2)};
}

})

7.4 Spectral hole burning (slide 82)

A strong beam at \(\nu_s\) saturates the atoms it interacts with. In a homogeneous medium every atom sees the beam, so the whole gain curve drops. In an inhomogeneous medium only the atoms whose own (homogeneous) line overlaps \(\nu_s\) are saturated: a hole appears in the gain curve, of width \(\Delta\nu_h\sqrt{1+I/I_\text{sat}}\).

Show the Python 
viewof hb = Inputs.form({
  hom: Inputs.range([0.02, 3], {value: 0.15, step: 0.01, label: "homogeneous FWHM / inhomogeneous FWHM"}),
  I: Inputs.range([0, 50], {value: 5, step: 0.5, label: "saturating intensity I/I_sat"}),
  nus: Inputs.range([-1.5, 1.5], {value: 0.3, step: 0.01, label: "saturating frequency (units of inhomogeneous FWHM)"})
})
Show the Python 
hbOut = {
  const G = 1/(2*Math.sqrt(Math.LN2)), gam = hb.hom/2, Lr = d => gam*gam/(d*d + gam*gam);      // L normalised to 1 at centre
  const N = 401, data = [], cls = d3.range(N).map(i => -2.5 + 5*i/(N - 1)), w = cls.map(c => Math.exp(-(c*c)/(G*G)));
  let norm = 0; for (let k = 0; k < N; k++) norm += w[k]*Lr(cls[k]); // unsaturated gain at line centre, for normalisation
  for (let i = 0; i <= 300; i++) {
    const nu = -2 + 4*i/300; let g0 = 0, g = 0;
    for (let k = 0; k < N; k++) { const l = w[k]*Lr(nu - cls[k]); g0 += l; g += l/(1 + hb.I*Lr(hb.nus - cls[k])); }
    data.push({nu, g: g0/norm, who: "unsaturated"}, {nu, g: g/norm, who: "with saturating beam"});
  }
  return {data};
}
Plot.plot({
  width: Math.min(width, 1050), height: 280, x: {label: "ν − ν₀ (units of the inhomogeneous FWHM)"}, y: {label: "gain (normalised)", grid: true},
  color: {legend: true, range: ["#c3c2b7", "#2a78d6"]},
  marks: [Plot.line(hbOut.data, {x: "nu", y: "g", stroke: "who", strokeWidth: 2}), Plot.ruleX([hb.nus], {stroke: "#e34948", strokeDasharray: "4,3"})]
})

Make the homogeneous width larger than the inhomogeneous one: the hole widens until the whole curve sinks uniformly. This is the key difference of slide 83. In a homogeneous medium the first mode to reach threshold clamps the gain everywhere and the others stay below threshold: single-mode operation (Nd:YAG, in principle). In an inhomogeneous medium each mode burns its own hole and several modes lase at once (He–Ne). In a He–Ne laser each mode burns two holes, at \(\nu_m\) and \(2\nu_0-\nu_m\), because the standing wave interacts with atoms moving in both directions. Spatial hole burning in the standing wave breaks the single-mode rule of homogeneous media in practice.

TipGoing further
  • Lifetime broadening from a Fourier transform. Sample \(E(t)=e^{-t/2\tau}\cos\omega_0t\) for \(t\ge0\), take np.fft.fft and fit a Lorentzian to \(|E(\nu)|^2\). Check that the FWHM is \(1/2\pi\tau\).
  • Spatial hole burning. In a standing-wave cavity the intensity has nodes every \(\lambda/2n\). Atoms at the nodes are not saturated by the lasing mode and provide gain for a second mode. This is why Nd:YAG lasers are multimode unless they use a ring cavity or a twisted-mode cavity.
  • Inhomogeneous broadening in semiconductors? The gain of a bulk semiconductor is homogeneously broadened by fast intraband scattering (0.1 ps). Quantum-dot lasers, with their size distribution, are strongly inhomogeneous: they lase on many modes and are used for frequency combs.

```{ojs}
  const G = 1/(2*Math.sqrt(Math.LN2)), gam = hb.hom/2, Lr = d => gam*gam/(d*d + gam*gam);      // L normalised to 1 at centre
  const N = 401, data = [], cls = d3.range(N).map(i => -2.5 + 5*i/(N - 1)), w = cls.map(c => Math.exp(-(c*c)/(G*G)));
  let norm = 0; for (let k = 0; k < N; k++) norm += w[k]*Lr(cls[k]); // unsaturated gain at line centre, for normalisation
  for (let i = 0; i <= 300; i++) {
    const nu = -2 + 4*i/300; let g0 = 0, g = 0;
    for (let k = 0; k < N; k++) { const l = w[k]*Lr(nu - cls[k]); g0 += l; g += l/(1 + hb.I*Lr(hb.nus - cls[k])); }
    data.push({nu, g: g0/norm, who: "unsaturated"}, {nu, g: g/norm, who: "with saturating beam"});
  }
  return {data};
}
Plot.plot({
  width: Math.min(width, 1050), height: 280, x: {label: "ν − ν₀ (units of the inhomogeneous FWHM)"}, y: {label: "gain (normalised)", grid: true},
  color: {legend: true, range: ["#c3c2b7", "#2a78d6"]},
  marks: [Plot.line(hbOut.data, {x: "nu", y: "g", stroke: "who", strokeWidth: 2}), Plot.ruleX([hb.nus], {stroke: "#e34948", strokeDasharray: "4,3"})]
})
```

Make the homogeneous width larger than the inhomogeneous one: the hole widens until the whole curve sinks uniformly. This is the
key difference of slide 83. In a **homogeneous** medium the first mode to reach threshold clamps the gain everywhere and the others
stay below threshold: single-mode operation (Nd:YAG, in principle). In an **inhomogeneous** medium each mode burns its own hole and
several modes lase at once (He–Ne). In a He–Ne laser each mode burns two holes, at $\nu_m$ and $2\nu_0-\nu_m$, because the
standing wave interacts with atoms moving in both directions. Spatial hole burning in the standing wave breaks the single-mode rule
of homogeneous media in practice.

## Going further
- **Lifetime broadening from a Fourier transform.** Sample $E(t)=e^{-t/2\tau}\cos\omega_0t$ for $t\ge0$, take `np.fft.fft` and fit a
  Lorentzian to $|E(\nu)|^2$. Check that the FWHM is $1/2\pi\tau$.
- **Spatial hole burning.** In a standing-wave cavity the intensity has nodes every $\lambda/2n$. Atoms at the nodes are not
  saturated by the lasing mode and provide gain for a second mode. This is why Nd:YAG lasers are multimode unless they use a ring
  cavity or a twisted-mode cavity.
- **Inhomogeneous broadening in semiconductors?** The gain of a bulk semiconductor is homogeneously broadened by fast intraband
  scattering (0.1 ps). Quantum-dot lasers, with their size distribution, are strongly inhomogeneous: they lase on many modes and
  are used for frequency combs.
:::
