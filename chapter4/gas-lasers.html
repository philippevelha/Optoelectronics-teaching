5.1 Key relations

In the He–Ne laser (slides 45–47) an electrical discharge excites helium atoms into the metastable \(2^1S_0\) and \(2^3S_1\) states. Their energies (20.61 and 19.82 eV) almost coincide with the Ne \(3s_2\) and \(2s_2\) levels, so a collision hands the energy over, \(\text{He}^*+\text{Ne}\to\text{He}+\text{Ne}^*\). The excited Ne atoms are inverted with respect to the short-lived \(2p\) levels. The \(3s_2\to2p_4\) transition gives the red line at 632.8 nm; other transitions give the green, yellow, orange and infrared lines of slide 52.

The two mirrors at distance \(L\) form a Fabry–Perot resonator. Only standing waves with a whole number of half wavelengths fit (slides 48–49):

\[ m\frac{\lambda_m}{2n}=L,\qquad \nu_m=m\frac{c}{2nL},\qquad \Delta\nu_m=\frac{c}{2nL},\qquad \Delta\lambda_m\approx\frac{\lambda^2}{2nL}. \]

The output spectrum is the product of these longitudinal modes with the optical gain curve of the medium. In a gas the gain curve is Doppler broadened: atoms moving toward the mirror see a blue-shifted frequency, atoms moving away a red-shifted one. The Maxwell velocity distribution makes the curve Gaussian with FWHM (slide 49)

\[ \Delta\nu_{1/2}=2\nu_0\sqrt{\frac{2k_BT\ln2}{Mc^2}},\qquad \Delta\lambda_{1/2}\approx\Delta\nu_{1/2}\frac{\lambda}{\nu}. \]

Show the Python 
glOut = {
  const [lam0, Mg] = gasLines[gl.line], c = 299792458, k = 1.380649e-23, M = Mg*1e-3/6.02214076e23;
  const nu0 = c/(lam0*1e-9), fw = 2*nu0*Math.sqrt(2*k*gl.T*Math.log(2)/(M*c*c)), dnm = c/(2*gl.L*1e-2);
  const G = f => Math.exp(-4*Math.log(2)*(f/fw)**2), span = 1.6*fw, curve = [], modes = [];
  for (let i = 0; i <= 400; i++) { const f = -span + 2*span*i/400; curve.push({f: f/1e9, g: G(f)}); }
  const m0 = Math.round(-span/dnm) - 1, m1 = Math.round(span/dnm) + 1;
  if (m1 - m0 < 4000) for (let m = m0; m <= m1; m++) { const f = (m + gl.shift)*dnm; if (Math.abs(f) <= span) modes.push({f: f/1e9, g: G(f), lase: G(f) > gl.thr}); }
  const nLase = modes.filter(d => d.lase).length;
  return {fw, dnm, curve, modes, nLase, lam0, nu0, dlam: fw*lam0/nu0, mnum: 2*gl.L*1e-2/(lam0*1e-9)};
}

Two consequences show up immediately:

  • The number of lasing modes depends on where the comb sits under the gain curve (“mode position”). Moving the comb by half a spacing changes the count by one. In a real laser the cavity length drifts thermally by many wavelengths, so the modes slide under the curve and the output power fluctuates (“mode sweeping”).
  • A cavity shorter than about \(c/(2\Delta\nu_{1/2})\approx10\) cm keeps a single He–Ne mode above threshold. Single-frequency He–Ne lasers are short, and their output is low.

TipGoing further
  • Mode competition in an inhomogeneous medium. Each longitudinal mode interacts with its own velocity class of atoms, at \(\pm v=c(\nu_m-\nu_0)/\nu_0\). Modes do not steal each other’s atoms, so several modes lase together. Compare with the homogeneously broadened Nd:YAG laser in Chapter 7.
  • Lamb dip. A mode tuned exactly to \(\nu_0\) interacts with the \(v=0\) atoms in both directions of travel, so it has fewer atoms available than a slightly detuned mode. The output power versus cavity tuning shows a dip at line centre, used to stabilise He–Ne lasers to about \(10^{-9}\).
  • Brewster windows. The tube windows are tilted at Brewster’s angle (Ch. 1): the p polarisation passes without loss, the s polarisation loses about 15 % per pass. Compute the round-trip loss of each polarisation with the Fresnel equations and show why the output is linearly polarised.
  • Isotope shift. ²⁰Ne and ²²Ne lines differ by about 900 MHz at 632.8 nm. Commercial tubes use a mixture to broaden the gain curve. Model the gain as the sum of two Gaussians.

  stabilise He–Ne lasers to about $10^{-9}$.
- **Brewster windows.** The tube windows are tilted at Brewster's angle (Ch. 1): the p polarisation passes without loss, the s
  polarisation loses about 15 % per pass. Compute the round-trip loss of each polarisation with the Fresnel equations and show why
  the output is linearly polarised.
- **Isotope shift.** ²⁰Ne and ²²Ne lines differ by about 900 MHz at 632.8 nm. Commercial tubes use a mixture to broaden the gain
  curve. Model the gain as the sum of two Gaussians.
:::
