Slide 75 shows transverse modes and slide 48 the longitudinal modes of a cavity, but the chapter never asks which mirrors make a cavity work, how large the beam is, or at which frequencies the transverse modes oscillate. This chapter answers these questions with the Gaussian beams of Chapter 1.

18.1 Key relations

A Gaussian beam (Ch. 1) has a waist \(w_0\) and a wavefront radius \(R(z)=z[1+(z_R/z)^2]\), with \(z_R=\pi w_0^2/\lambda\). It is a mode of a two-mirror cavity if, at each mirror, its wavefront curvature matches the mirror curvature. With the stability parameters

\[ g_1=1-\frac{L}{R_1},\qquad g_2=1-\frac{L}{R_2}\qquad(R=\infty\text{ for a flat mirror}), \]

such a beam exists only if

\[ 0\le g_1g_2\le1 \qquad\text{(stable resonator)}. \]

Its size on the mirrors and at the waist are

\[ w_1^2=\frac{\lambda L}{\pi}\sqrt{\frac{g_2}{g_1(1-g_1g_2)}},\quad w_2^2=\frac{\lambda L}{\pi}\sqrt{\frac{g_1}{g_2(1-g_1g_2)}},\quad w_0^2=\frac{\lambda L}{\pi}\frac{\sqrt{g_1g_2(1-g_1g_2)}}{|g_1+g_2-2g_1g_2|}. \]

The Hermite–Gauss modes TEM\(_{mn}\) (slide 75) accumulate an extra Gouy phase \((m+n+1)\arccos\sqrt{g_1g_2}\) per pass, so their resonance frequencies are

\[ \nu_{qmn}=\frac{c}{2nL}\left[q+(m+n+1)\frac{\arccos(\pm\sqrt{g_1g_2})}{\pi}\right], \]

with the sign of \(g_1\) (and \(g_2\)). Transverse modes thus add frequencies between the longitudinal modes of Chapter 5.

rsOut = {
  const L = rs.L*1e-2, R1 = rs.flat1 ? Infinity : rs.R1*1e-2, R2 = rs.R2*1e-2, lam = rs.lam*1e-9;
  const g1 = 1 - L/R1, g2 = 1 - L/R2, G = g1*g2, stable = G >= 0 && G < 1 && !(g1 === 0 && g2 !== 0) && !(g2 === 0 && g1 !== 0);
  const s = lam*L/Math.PI;
  const ratio = Math.abs(g1 - g2) < 1e-9 ? 1 : g2/g1;
  const w1 = stable ? Math.sqrt(s*Math.sqrt(ratio/(1 - G))) : NaN, w2 = stable ? Math.sqrt(s*Math.sqrt(1/(ratio*(1 - G)))) : NaN;
  const sym = Math.abs(g1 - g2) < 1e-9;                              // symmetric cavity: avoid 0/0 (confocal)
  const w0 = !stable ? NaN : sym ? Math.sqrt(s*Math.sqrt((1 + g1)/(4*(1 - g1)))) : Math.sqrt(s*Math.sqrt(G*(1 - G))/Math.abs(g1 + g2 - 2*G));
  const zw = !stable ? NaN : sym ? L/2 : L*g2*(1 - g1)/(g1 + g2 - 2*G);  // waist position from mirror 1
  const zR = Math.PI*w0*w0/lam, beam = [];
  if (stable) for (let i = 0; i <= 200; i++) { const z = L*i/200, w = w0*Math.sqrt(1 + ((z - zw)/zR)**2); beam.push({z: z*100, w: w*1e3}, {z: z*100, w: -w*1e3}); }
  const gouy = stable ? Math.acos(Math.sign(g1)*Math.sqrt(G))/Math.PI : NaN, fsr = 299792458/(2*L), spec = [];
  if (stable) for (let q = 0; q <= 2; q++) for (let mn = 0; mn <= 6; mn++) spec.push({f: (q + (mn + 1)*gouy)*fsr/1e6, h: 1/(1 + 0.6*mn), mn: `m+n = ${mn}`});
  return {g1, g2, G, stable, w1, w2, w0, zw, beam, gouy, fsr, spec};
}

Try the special cases:

  • Confocal (\(R_1=R_2=L\), \(g_1=g_2=0\)): the transverse-mode spacing is exactly \(c/4L\). Modes of different \(m+n\) coincide with longitudinal modes or fall exactly halfway: the cavity is highly degenerate, the principle of the scanning Fabry–Perot spectrum analyser.
  • Hemispherical (flat + \(R_2=L\), \(g_1=1\), \(g_2=0\)): the cavity sits exactly on the stability boundary and the mode would shrink to a point on the flat mirror. Shorten \(L\) by 1 cm to see the tightly focused mode; lengthen it and the cavity becomes unstable.
  • He–Ne laser: flat output coupler and \(R_2\approx1\) m with \(L=40\) cm. The beam radius is about 0.3 mm, so a 0.8 mm tube (slide 73) acts as an aperture that suppresses higher-order modes.

18.3 Why stability matters for lasers

The mode volume \(\approx\pi w_0^2L/2\) decides how many atoms contribute to the gain, and the mode size on the mirrors decides how much light is clipped by the apertures. Near the stability edges (\(g_1g_2\to0\) or \(1\)) the mode becomes very small or very large and sensitive to misalignment. Most lasers are designed well inside the stable region. High-power lasers with large-volume, high-gain media sometimes use unstable resonators on purpose: the beam fills the medium, and the output leaves around the edge of a small mirror.

TipGoing further
  • ABCD matrices. Write the round-trip matrix \(M\) of the cavity (propagation, mirror, propagation, mirror). Stability is \(|A+D|/2\le1\), and the self-consistent \(q\) parameter solves \(q=(Aq+B)/(Cq+D)\). Check that this reproduces \(w_1\) above, then add a thermal lens (Chapter 3) inside the cavity.
  • Laser diodes. Edge-emitter waveguides guide the mode, so the stability analysis is replaced by the waveguide modes of Ch. 2. In an external-cavity laser (Chapter 14), the lens and grating form an ABCD system again.
  • Fox–Li iteration. Propagate an arbitrary field back and forth between two finite mirrors with the angular-spectrum method (the holography code of Chapter 17) and watch it converge to TEM\(_{00}\), with a diffraction loss per pass that depends on the Fresnel number \(a^2/\lambda L\).

## Going further
- **ABCD matrices.** Write the round-trip matrix $M$ of the cavity (propagation, mirror, propagation, mirror). Stability is
  $|A+D|/2\le1$, and the self-consistent $q$ parameter solves $q=(Aq+B)/(Cq+D)$. Check that this reproduces $w_1$ above, then add
  a thermal lens (@sec-pumping) inside the cavity.
- **Laser diodes.** Edge-emitter waveguides guide the mode, so the stability analysis is replaced by the waveguide modes of Ch. 2.
  In an external-cavity laser (@sec-single-mode), the lens and grating form an ABCD system again.
- **Fox–Li iteration.** Propagate an arbitrary field back and forth between two finite mirrors with the angular-spectrum method
  (the holography code of @sec-holography) and watch it converge to TEM$_{00}$, with a diffraction loss per pass that depends on
  the Fresnel number $a^2/\lambda L$.

## Try it yourself

1. Find the range of $L$ for which a cavity with $R_1=R_2=50$ cm is stable.
2. For the He–Ne laser, compute the frequency of the TEM$_{01}$ mode relative to TEM$_{00}$. Could it fall inside the 1.5 GHz
   Doppler gain curve?
3. Show that the confocal cavity has the smallest mirror spot sizes for a given $L$ among symmetric cavities.
4. A 1 m CO₂ laser has a 6 mm bore. Which mirror radius gives a TEM$_{00}$ mode that fills 2/3 of the bore at the curved mirror?
