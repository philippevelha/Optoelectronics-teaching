13.1 Key relations

When the active layer is thinner than about 20 nm, the motion of the carriers across it is quantised (Chapter 3, quantum wells). For an infinite well of width \(d\) the electron and hole levels above the band edges are

\[ \varepsilon_n=\frac{h^2n^2}{8m_e^*d^2},\qquad \varepsilon'_{n'}=\frac{h^2n'^2}{8m_h^*d^2}, \]

and the radiative transitions obey the selection rule \(\Delta n=n-n'=0\). The emitted photon is therefore

\[ h\nu=E_g+\varepsilon_1+\varepsilon'_1 . \]

The density of states becomes a staircase that is finite at the band edge (slide 135c). Carriers fill the first sub-band instead of spreading over a \(\sqrt E\) band, so inversion is reached with fewer carriers, the gain spectrum is narrower and the threshold current is lower. The well is too thin to guide light: a single quantum well (SQW) overlaps only a few percent of the mode. Multiple quantum wells (MQW, slide 136) or a separate-confinement heterostructure (SCH, a wider waveguide around the well) restore the optical confinement.

qwScan = {
  const hbar = 1.054571817e-34, me0 = 9.1093837e-31, q = 1.602176634e-19, h = 6.62607015e-34;
  const first = (V0, m, d) => { const k = E => Math.sqrt(2*m*me0*E*q)/hbar, K = E => Math.sqrt(2*m*me0*(V0 - E)*q)/hbar;
    const f = E => k(E)*Math.sin(k(E)*d/2) - K(E)*Math.cos(k(E)*d/2); let a = V0*1e-7, b = V0*(1 - 1e-7);
    // the ground state is the first root of the even equation; bracket it by scanning
    let Ep = a, fp = f(a); for (let i = 1; i <= 2000; i++) { const E = a + (b - a)*i/2000, fe = f(E); if (fp*fe < 0) { b = E; a = Ep; break; } Ep = E; fp = fe; }
    for (let j = 0; j < 60; j++) { const c = (a + b)/2; if (f(a)*f(c) <= 0) b = c; else a = c; } return (a + b)/2; };
  const out = [];
  for (let w = 2; w <= 30; w += 0.5) {
    const d = w*1e-9, Ef = qw.Eg + first(qw.dEc, qw.me, d) + first(qw.dEv, qw.mh, d);
    const Ei = qw.Eg + (h**2/(8*qw.me*me0*d*d) + h**2/(8*qw.mh*me0*d*d))/q;
    out.push({w, lam: 1239.84/Ef, who: "finite well"}, {w, lam: 1239.84/Ei, who: "infinite well"});
  }
  return out;
}

13.4 Optical confinement: SQW, MQW and SCH (slides 135–136)

The confinement factor of a thin active layer in a symmetric slab falls as \(d^2\) (Botez approximation \(\Gamma\approx D^2/(2+D^2)\), \(D=k_0d\sqrt{n_a^2-n_c^2}\)). A 10 nm well confines less than 1 % of the light.

Show the Python 
k0 = 2*np.pi/850e-9; na, nc = 3.6, 3.4
dd = np.logspace(-9 + 0.7, -6, 300)
D = k0*dd*np.sqrt(na**2 - nc**2); G = D**2/(2 + D**2)
G1 = (k0*10e-9*np.sqrt(na**2 - nc**2))**2/2
Gguide = (lambda D: D**2/(2 + D**2))(k0*0.2e-6*np.sqrt(na**2 - nc**2))
Gsch = Gguide*10e-9/0.2e-6*1.5
fig, ax = plt.subplots(figsize=(7.5, 3.6))
ax.loglog(dd*1e9, G, label="bulk active layer of thickness d")
ax.plot(10, G1, "o", color=lz.PALETTE[7], label=f"SQW 10 nm: Γ = {G1:.2%}")
ax.plot(40, 4*Gsch, "s", color=lz.PALETTE[2], label=f"4 × 10 nm wells in a 0.2 µm guide: Γ ≈ {4*Gsch:.1%}")
ax.plot(10, Gsch, "D", color=lz.PALETTE[3], label=f"SQW in a 0.2 µm SCH guide: Γ ≈ {Gsch:.1%}")
ax.set(xlabel="active thickness d (nm)", ylabel="confinement factor Γ"); ax.legend(fontsize=8); plt.show()

A low \(\Gamma\) is not fatal: the threshold condition is \(\Gamma g_{th}=\alpha_t\). The QW gain per carrier is large and only a tiny volume has to be inverted, so the threshold current of a well-designed SCH-MQW laser is still several times lower than that of a DH laser. Modern laser diodes (slide 116: red, violet, telecom) are all quantum-well lasers.

All quantum-well designs beat the DH by a factor of 4 to 9 in threshold current, because far less material has to be inverted. Within this radiative-only model the single well even has the lowest current. But it needs a gain of 1000 cm⁻¹ at \(3\times10^{18}\) cm⁻³, close to the maximum that one sub-band can provide, so any extra loss (a shorter cavity, a hotter chip) pushes it beyond reach. Three to five wells run at lower density, where Auger recombination and carrier leakage, which grow as \(n^3\) and are ignored here, stay small. This margin is why practical lasers use MQWs. The numbers are indicative only: real QW gain depends on strain, well depth and temperature.

TipGoing further
  • Strained quantum wells. Growing a well with a slightly different lattice constant (InGaAs on GaAs, a few % In) splits the heavy and light holes and lowers the in-plane hole mass. Transparency density and threshold drop by a further factor of two; this made 980 nm EDFA pumps practical.
  • Quantum-dot lasers. Confining in three dimensions gives delta-like densities of states: very low thresholds, high \(T_0\), and tolerance to defects that allows growth on silicon.
  • Quantum cascade lasers. Transitions between sub-bands of the conduction band (\(\varepsilon_2\to\varepsilon_1\)) emit in the mid-infrared (3–20 µm) and THz range; the wavelength is set by layer thicknesses only. With the panel, find the well width for which \(\varepsilon_2-\varepsilon_1\) of an InGaAs/AlInAs well (\(\Delta E_c=0.52\) eV, \(m^*=0.043m_e\)) equals 0.13 eV (≈ 9.5 µm).

> $m_e^*=0.07m_e$, $m_h^*=0.50m_e$, $E_g=1.42$ eV. Find the first two electron levels, the first hole level and the emission
> wavelength shift with respect to bulk GaAs (infinite well). The slide also quotes the finite-well values.

```{python}
#| label: tbl-qw-example
#| tbl-cap: "Slides 137–139 recomputed. The finite-well values of the slide (0.031, 0.121, 0.007 eV, 848 nm) are close to the direct solution."
d = 10e-9
e_inf = lz.qw_infinite([1, 2], d, 0.07); h_inf = lz.qw_infinite(1, d, 0.50)
e_fin = lz.qw_finite(d, 0.28, 0.07); h_fin = lz.qw_finite(d, 0.16, 0.50)
lg = lz.wavelength_from_eV(1.42)*1e9
li = lz.wavelength_from_eV(1.42 + e_inf[0] + h_inf)*1e9
lf = lz.wavelength_from_eV(1.42 + e_fin[0] + h_fin[0])*1e9
pd.DataFrame([("ε₁, ε₂ (eV)", f"{e_inf[0]:.4f}, {e_inf[1]:.4f}", "0.0537, 0.215", f"{e_fin[0]:.4f}, {e_fin[1]:.4f}", "0.031, 0.121"),
              ("ε'₁ (eV)", f"{h_inf:.4f}", "0.0075", f"{h_fin[0]:.4f}", "0.007"),
              ("λ bulk (nm)", f"{lg:.1f}", "874", f"{lg:.1f}", "874"),
              ("λ QW (nm)", f"{li:.1f}", "838", f"{lf:.1f}", "848"),
              ("shift λ_g − λ_QW (nm)", f"{lg - li:.1f}", "36", f"{lg - lf:.1f}", "26")],
             columns=["quantity", "infinite well", "slide (infinite)", "finite well", "slide (finite)"])
```

The infinite-well numbers match. The direct finite-well solution gives levels about 5 % higher than those quoted on the slide
(probably a slightly heavier mass or a different matching condition) and a shift of 23 nm instead of 26 nm. The conclusion is
unchanged: the well width tunes the wavelength by tens of nanometres, without changing the material.

## Optical confinement: SQW, MQW and SCH (slides 135–136)

The confinement factor of a thin active layer in a symmetric slab falls as $d^2$ (Botez approximation
$\Gamma\approx D^2/(2+D^2)$, $D=k_0d\sqrt{n_a^2-n_c^2}$). A 10 nm well confines less than 1 % of the light.

```{python}
#| label: fig-qw-gamma
#| fig-cap: "Confinement factor at 850 nm of a GaAs layer (n = 3.6) in Al₀.₃Ga₀.₇As (n = 3.4) versus its total thickness (Botez approximation). Markers: a single 10 nm well, 4 wells (MQW, Γ ≈ 4 × the single-well value when the wells sit inside a guide) and a 10 nm well at the centre of a 0.2 µm separate-confinement waveguide (Γ ≈ guide confinement × d_well/d_guide × peak enhancement)."
k0 = 2*np.pi/850e-9; na, nc = 3.6, 3.4
dd = np.logspace(-9 + 0.7, -6, 300)
D = k0*dd*np.sqrt(na**2 - nc**2); G = D**2/(2 + D**2)
G1 = (k0*10e-9*np.sqrt(na**2 - nc**2))**2/2
Gguide = (lambda D: D**2/(2 + D**2))(k0*0.2e-6*np.sqrt(na**2 - nc**2))
Gsch = Gguide*10e-9/0.2e-6*1.5
fig, ax = plt.subplots(figsize=(7.5, 3.6))
ax.loglog(dd*1e9, G, label="bulk active layer of thickness d")
ax.plot(10, G1, "o", color=lz.PALETTE[7], label=f"SQW 10 nm: Γ = {G1:.2%}")
ax.plot(40, 4*Gsch, "s", color=lz.PALETTE[2], label=f"4 × 10 nm wells in a 0.2 µm guide: Γ ≈ {4*Gsch:.1%}")
ax.plot(10, Gsch, "D", color=lz.PALETTE[3], label=f"SQW in a 0.2 µm SCH guide: Γ ≈ {Gsch:.1%}")
ax.set(xlabel="active thickness d (nm)", ylabel="confinement factor Γ"); ax.legend(fontsize=8); plt.show()
```

A low $\Gamma$ is not fatal: the threshold condition is $\Gamma g_{th}=\alpha_t$. The QW gain per carrier is large and only a
tiny volume has to be inverted, so the threshold **current** of a well-designed SCH-MQW laser is still several times lower than
that of a DH laser. Modern laser diodes (slide 116: red, violet, telecom) are all quantum-well lasers.

```{python}
#| label: tbl-qw-vs-dh
#| tbl-cap: "Rough threshold comparison at equal cavity (L = 300 µm, W = 3 µm, R = 0.32, α_s = 10 cm⁻¹). The QW gain uses the textbook logarithmic law g = g₀ ln(n/n_tr) with g₀ = 2000 cm⁻¹, n_tr = 1.8×10¹⁸ cm⁻³; the DH uses the slide-130 GaAs curve. Radiative recombination with B = 2×10⁻¹⁰ cm³/s."
L, W, R, a_s, B = 300e-6, 3e-6, 0.32, 1e3, 2e-16
at = lz.threshold_gain(a_s, L, R)
rows = []
# DH, d = 0.15 µm, Γ from Botez
d = 0.15e-6; Dd = k0*d*np.sqrt(na**2 - nc**2); Gm = Dd**2/(2 + Dd**2)
nth = lz.n_for_gain_slide(at/Gm/100)*lz.CM3
rows.append(("DH, d = 150 nm", f"{Gm:.2f}", f"{at/Gm/100:.0f}", f"{nth/lz.CM3:.2e}", f"{lz.qe*B*nth**2*d*L*W*1e3:.1f}"))
for N in (1, 3, 5):
    Gq = N*Gsch
    g = at/Gq/100
    nq = 1.8e18*np.exp(g/2000)*lz.CM3
    rows.append((f"{N} × 10 nm QW in SCH", f"{Gq:.3f}", f"{g:.0f}", f"{nq/lz.CM3:.2e}", f"{lz.qe*B*nq**2*N*10e-9*L*W*1e3:.1f}"))
pd.DataFrame(rows, columns=["active region", "Γ", "g_th (cm⁻¹)", "n_th (cm⁻³)", "radiative I_th (mA)"])
```

All quantum-well designs beat the DH by a factor of 4 to 9 in threshold current, because far less material has to be inverted.
Within this radiative-only model the single well even has the lowest current. But it needs a gain of 1000 cm⁻¹ at
$3\times10^{18}$ cm⁻³, close to the maximum that one sub-band can provide, so any extra loss (a shorter cavity, a hotter chip)
pushes it beyond reach. Three to five wells run at lower density, where Auger recombination and carrier leakage, which grow as
$n^3$ and are ignored here, stay small. This margin is why practical lasers use MQWs. The numbers are indicative only: real QW
gain depends on strain, well depth and temperature.

## Going further
- **Strained quantum wells.** Growing a well with a slightly different lattice constant (InGaAs on GaAs, a few % In) splits the
  heavy and light holes and lowers the in-plane hole mass. Transparency density and threshold drop by a further factor of two;
  this made 980 nm EDFA pumps practical.
- **Quantum-dot lasers.** Confining in three dimensions gives delta-like densities of states: very low thresholds, high $T_0$, and
  tolerance to defects that allows growth on silicon.
- **Quantum cascade lasers.** Transitions *between sub-bands* of the conduction band ($\varepsilon_2\to\varepsilon_1$) emit in the
  mid-infrared (3–20 µm) and THz range; the wavelength is set by layer thicknesses only. With the panel, find the well width for
  which $\varepsilon_2-\varepsilon_1$ of an InGaAs/AlInAs well ($\Delta E_c=0.52$ eV, $m^*=0.043m_e$) equals 0.13 eV (≈ 9.5 µm).
:::
