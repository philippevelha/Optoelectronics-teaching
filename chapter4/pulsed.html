8.1 Key relations

Q-switching (slides 84–87). The quality factor \(Q\) of the cavity is kept low (a mirror is blocked or misaligned) while the pump builds up an inversion \(N_i\) far above the normal threshold \(N_{th}\). The medium stores energy because its upper level is long-lived (ms for Nd:YAG and ruby, Chapter 2). Then \(Q\) is switched high in nanoseconds. The photon density grows from spontaneous noise at the rate \((N/N_{th}-1)/\tau_c\), where \(\tau_c\) is the photon lifetime of the high-\(Q\) cavity, and a giant pulse empties the inversion. Without pumping during the pulse, the four-level rate equations in normalised form (\(n=N/N_{th}\), time in units of \(\tau_c\)) are

\[ \frac{dn}{dt}=-n\phi,\qquad \frac{d\phi}{dt}=(n-1)\phi . \]

Their solution gives the fraction \(\eta\) of the stored inversion that is extracted, from \(r\eta=-\ln(1-\eta)\) with \(r=N_i/N_{th}\), and the peak photon density \(\phi_\text{max}=r-1-\ln r\) (in units of \(N_{th}\)), reached when \(n=1\).

Mode-locking (slide 88). A laser oscillating on \(N\) longitudinal modes spaced by \(\delta\nu=c/2L\) emits their sum. If the phases are random, the output is noisy around its average. If the phases are locked (equal), the modes add in phase once per round trip \(T=2L/c\) and produce a train of pulses of width

\[ \Delta t\approx\frac{T}{N}\approx\frac{1}{\Delta\nu},\qquad P_\text{peak}\approx N\,P_\text{average}. \]

The pulse width is set by the gain bandwidth \(\Delta\nu\): the broader the gain, the shorter the pulse.

qsOut = {
  const tEnd = 30*Math.max(1, 4/(qs.r - 1)) + 20;
  const sol = rk4((t, [n, p]) => [-n*p, (n - 1)*p], [qs.r, 10 ** qs.phi0], 0, tEnd, 6000, 10);
  const data = sol.flatMap(({t, y}) => [{t: t*qs.tc, v: y[0], who: "inversion n = N/N_th"}, {t: t*qs.tc, v: y[1], who: "photon density φ (units of N_th)"}]);
  const ph = sol.map(d => d.y[1]), pk = d3.max(ph), ipk = ph.indexOf(pk);
  const above = sol.filter(d => d.y[1] >= pk/2), fw = (above[above.length - 1].t - above[0].t)*qs.tc;
  // solve r η = −ln(1 − η) by bisection
  let a = 1e-9, b = 1 - 1e-12; for (let i = 0; i < 100; i++) { const c = (a + b)/2; if (qs.r*c + Math.log(1 - c) > 0) a = c; else b = c; }
  return {data, pk, tpk: sol[ipk].t*qs.tc, fw, eta: (a + b)/2, nf: sol[sol.length - 1].y[0]};
}

  shape: Inputs.radio(["equal amplitudes", "Gaussian gain envelope"], {value: "equal amplitudes", label: "mode amplitudes"})
})
Show the Python 
mlOut = {
  const c = 299792458, T = 2*ml.L/c, dnu = 1/T;
  let s = ml.seed*9301 + 49297; const rnd = () => (s = (s*9301 + 49297) % 233280)/233280;
  const ph = d3.range(ml.N).map(() => ml.locked.startsWith("locked") ? 0 : 2*Math.PI*rnd());
  const amp = d3.range(ml.N).map(k => ml.shape.startsWith("equal") ? 1 : Math.exp(-((k - (ml.N - 1)/2)**2)/(2*(ml.N/4 + 0.5)**2)));
  const P = amp.reduce((a, b) => a + b*b, 0), data = [];
  for (let i = 0; i <= 1500; i++) {
    const t = 3*T*i/1500; let re = 0, im = 0;
    for (let k = 0; k < ml.N; k++) { const a = 2*Math.PI*(k - (ml.N - 1)/2)*dnu*t + ph[k]; re += amp[k]*Math.cos(a); im += amp[k]*Math.sin(a); }
    data.push({t: t*1e9, I: (re*re + im*im)/P});
  }
  const peak = d3.max(data, d => d.I);
  return {data, T, dnu, peak};
}
Plot.plot({
  width: Math.min(width, 1050), height: 280, x: {label: "time (ns)"}, y: {label: "intensity / average intensity", grid: true},

})

TipGoing further
  • How are the phases locked? Active mode-locking modulates the loss (or the gain) at exactly \(c/2L\) (the EO switch of slide 88c): each mode acquires sidebands that coincide with its neighbours and injection-locks them. Passive mode-locking uses a saturable absorber, or the Kerr lens of the gain crystal (Ti:sapphire), which favours high peak intensity. Write the field as a sum of modes with a sinusoidal loss modulation and iterate it round trip by round trip.
  • Frequency combs. The mode-locked spectrum is a comb of lines \(\nu_m=f_\text{ceo}+mf_\text{rep}\). Measuring and stabilising \(f_\text{ceo}\) with self-referencing earned the 2005 Nobel prize (Hall, Hänsch). Combs now calibrate astronomical spectrographs and link optical clocks.
  • Cavity dumping and regenerative amplifiers. Chirped-pulse amplification (Strickland and Mourou, Nobel 2018) stretches the mode-locked pulse, amplifies it and recompresses it to reach petawatt peak powers.
  • Passive Q-switching. A saturable absorber (Cr⁴⁺:YAG) switches \(Q\) by itself (slide 87b). Add an absorber population to the rate equations and show that the laser emits a regular pulse train whose repetition rate grows with the pump.

## Key relations

**Q-switching** (slides 84–87). The quality factor $Q$ of the cavity is kept low (a mirror is blocked or misaligned) while the
pump builds up an inversion $N_i$ far above the normal threshold $N_{th}$. The medium stores energy because its upper level is

$r=N_i/N_{th}$, and the peak photon density $\phi_\text{max}=r-1-\ln r$ (in units of $N_{th}$), reached when $n=1$.

  and link optical clocks.
- **Cavity dumping and regenerative amplifiers.** Chirped-pulse amplification (Strickland and Mourou, Nobel 2018) stretches the
  mode-locked pulse, amplifies it and recompresses it to reach petawatt peak powers.
- **Passive Q-switching.** A saturable absorber (Cr⁴⁺:YAG) switches $Q$ by itself (slide 87b). Add an absorber population to the
  rate equations and show that the laser emits a regular pulse train whose repetition rate grows with the pump.
:::
