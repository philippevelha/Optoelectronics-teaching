Appendix A — Running the notebooks

A.1 Three ways to use this companion

  1. Read the website. The live panels run in the browser with no installation.
  2. Run the code in Google Colab. Every chapter starts with an Open in Colab button. Colab is free and runs in the browser; you only need a Google account. Use File → Save a copy in Drive to keep your changes.
  3. Run it on your computer with Jupyter, or rebuild the whole book with Quarto.

A.2 Installation

pip install -r requirements.txt     # numpy scipy matplotlib pandas jupyter ipywidgets (+ optional colour-science)
quarto preview                      # live preview while editing
quarto render                       # builds _book/ (HTML)

Rendering executes every Python cell once. Results are cached in _freeze/ (freeze: auto), so later builds only re-run the chapters you changed.

A.3 Publishing the website (GitHub Pages)

The source lives at https://github.com/philippevelha/Optoelectronics-teaching (folder chapter3/) and the site at https://philippevelha.github.io/Optoelectronics-teaching/chapter3/. After editing a chapter:

cd notebooks && python build_notebooks.py && cd ..         # refresh the notebooks (Colab buttons point to them)
git add -A && git commit -m "Update chapter 3" && git push   # update the source on GitHub
bash ../publish.sh                                         # render and update the website

A.4 Regenerating the notebooks

cd notebooks
python build_notebooks.py

The script converts every chapter, adds a setup cell that works both locally and in Colab (it downloads semilib.py from GitHub when running in Colab), and rebuilds interactive_explorers.ipynb.

# Running the notebooks {#sec-running}

## Three ways to use this companion

1. **Read the website.** The live panels run in the browser with no installation.
2. **Run the code in Google Colab.** Every chapter starts with an **Open in Colab** button. Colab is free and runs in the browser;
   you only need a Google account. Use *File → Save a copy in Drive* to keep your changes.
3. **Run it on your computer** with Jupyter, or rebuild the whole book with Quarto.

```bash
pip install -r requirements.txt     # numpy scipy matplotlib pandas jupyter ipywidgets (+ optional colour-science)
quarto preview                      # live preview while editing

```

Rendering executes every Python cell once. Results are cached in `_freeze/` (`freeze: auto`), so later builds only re-run the
chapters you changed.
