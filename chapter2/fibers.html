Slides 40–64. A cylindrical core of radius \(a\) and index \(n_1\), inside a cladding of index \(n_2\). Two kinds of rays appear (slide 42). Meridional rays cross the axis. Skew rays spiral around it. In the wave picture the two families give the LP\(_{lm}\) modes.

2.1 Weakly guiding fibers and LP modes (slides 43–47)

When \(\Delta\ll1\) (typically 0.3 % to 2 %), the guided modes are almost transverse and linearly polarised:

\[ E_{LP}=E_{lm}(r,\phi)\,e^{j(\omega t-\beta_{lm}z)},\qquad E_{lm}(r,\phi)=f(r)\cos(l\phi)\ \text{or}\ f(r)\sin(l\phi). \]

Inside the core \(f(r)\propto J_l(ur/a)\) and in the cladding \(f(r)\propto K_l(wr/a)\), with \(u^2+w^2=V^2\). Continuity of \(f\) and \(f'\) at \(r=a\) gives the eigenvalue equation

\[ \frac{u\,J_{l-1}(u)}{J_l(u)}=-\frac{w\,K_{l-1}(w)}{K_l(w)} . \tag{2.1}\]

The mode index \(l\) sets the azimuthal order (\(2l\) maxima around a circle). The index \(m\) counts the radial maxima. The function fl.LP_b(V, l, m) solves Equation 2.1, and you can read it in fiberlib.py: it is a sign-change scan followed by Brent’s method.

2.2 Fiber parameters (slides 48, 61–62)

quantity formula
normalized index difference \(\Delta = \dfrac{n_1^2-n_2^2}{2n_1^2}\approx\dfrac{n_1-n_2}{n_1}\)
numerical aperture \(\mathrm{NA}=\sqrt{n_1^2-n_2^2}\approx n_1\sqrt{2\Delta}\)
acceptance angle \(\sin\alpha_\text{max} = \mathrm{NA}/n_0\)
\(V\)-number \(V=\dfrac{2\pi a}{\lambda}\,\mathrm{NA}\)
single mode \(V<2.405\), i.e. \(\lambda>\lambda_c=\dfrac{2\pi a\,\mathrm{NA}}{2.405}\)
number of modes (\(V\gg1\)) \(M\approx V^2/2\)

fiberOut = {
  const {n1, n2, d, lam} = fd, a = d / 2;
  if (!(n1 > n2)) return null;
  const NAv = Math.sqrt(n1*n1 - n2*n2), Dl = (n1*n1 - n2*n2) / (2*n1*n1);

}

2.4.1 Group velocity and group delay (slides 51–52)

SMF with \(n_1=1.4480\), \(n_2=1.4400\), \(a=3\) µm at \(\lambda=1.5\) µm. What are \(v_g\) and the group delay over 1 km? Neglect material dispersion.

The slides use \(\beta \approx n_2k[1+b\Delta]\) with the approximate \(b(V)\), and a 0.1 % finite difference. We do the same and also use the exact \(b(V)\) and an exact derivative.

Show the Python 
n1, n2, a = 1.4480, 1.4400, 3e-6
Dl = (n1 - n2) / n1
def beta(wl, exact):
    V = fl.V_number(a, wl, n1, n2)
    b = fl.LP_b(V, 0, 1) if exact else fl.b_approx(V)
    return n2 * 2 * np.pi / wl * (1 + b * Dl)
for exact, h in [(False, 1.5e-9), (True, 1e-12)]:
    w1, w2 = 1.5e-6, 1.5e-6 + h
    om = lambda wl: 2 * np.pi * c0 / wl
    vg = (om(w1) - om(w2)) / (beta(w1, exact) - beta(w2, exact))
    print(f"{'exact b(V), dλ→0' if exact else 'approx. b(V), dλ = 0.1%':<26s}: "
          f"b = {fl.LP_b(fl.V_number(a,w1,n1,n2),0,1) if exact else fl.b_approx(fl.V_number(a,w1,n1,n2)):.5f}, "
          f"v_g = {vg:.5e} m/s, τ_g(1 km) = {1e3/vg*1e6:.4f} µs")

2.5 Mode field diameter (slides 53–56)

The LP\(_{01}\) field is very close to a Gaussian \(E\propto\exp(-r^2/w^2)\). The MFD is \(2w\). Because the intensity is Gaussian, the fraction of power inside \(r<w\) is \(1-e^{-2}\approx 86\,\%\), just like a Gaussian beam (Chapter 1).

## Weakly guiding fibers and LP modes (slides 43–47)

When $\Delta\ll1$ (typically 0.3 % to 2 %), the guided modes are almost transverse and linearly polarised:

$$
E_{LP}=E_{lm}(r,\phi)\,e^{j(\omega t-\beta_{lm}z)},\qquad
E_{lm}(r,\phi)=f(r)\cos(l\phi)\ \text{or}\ f(r)\sin(l\phi).
$$

Inside the core $f(r)\propto J_l(ur/a)$ and in the cladding $f(r)\propto K_l(wr/a)$, with
$u^2+w^2=V^2$. Continuity of $f$ and $f'$ at $r=a$ gives the **eigenvalue equation**

$$
\frac{u\,J_{l-1}(u)}{J_l(u)}=-\frac{w\,K_{l-1}(w)}{K_l(w)} .
$$ {#eq-lp}

The mode index $l$ sets the azimuthal order ($2l$ maxima around a circle). The index $m$ counts the
radial maxima. The function `fl.LP_b(V, l, m)` solves @eq-lp, and you can read it in
[`fiberlib.py`](fiberlib.py): it is a sign-change scan followed by Brent's method.

## Fiber parameters (slides 48, 61–62)

| quantity | formula |
|---|---|
| normalized index difference | $\Delta = \dfrac{n_1^2-n_2^2}{2n_1^2}\approx\dfrac{n_1-n_2}{n_1}$ |
| numerical aperture | $\mathrm{NA}=\sqrt{n_1^2-n_2^2}\approx n_1\sqrt{2\Delta}$ |
| acceptance angle | $\sin\alpha_\text{max} = \mathrm{NA}/n_0$ |
| $V$-number | $V=\dfrac{2\pi a}{\lambda}\,\mathrm{NA}$ |
| single mode | $V<2.405$, i.e. $\lambda>\lambda_c=\dfrac{2\pi a\,\mathrm{NA}}{2.405}$ |
| number of modes ($V\gg1$) | $M\approx V^2/2$ |


### Group velocity and group delay (slides 51–52)

> SMF with $n_1=1.4480$, $n_2=1.4400$, $a=3$ µm at $\lambda=1.5$ µm. What are $v_g$ and the group delay
> over 1 km? Neglect material dispersion.

The slides use $\beta \approx n_2k[1+b\Delta]$ with the approximate $b(V)$, and a 0.1 % finite difference.
We do the same and also use the **exact** $b(V)$ and an exact derivative.

```{python}
n1, n2, a = 1.4480, 1.4400, 3e-6
Dl = (n1 - n2) / n1
def beta(wl, exact):
    V = fl.V_number(a, wl, n1, n2)
    b = fl.LP_b(V, 0, 1) if exact else fl.b_approx(V)
    return n2 * 2 * np.pi / wl * (1 + b * Dl)
for exact, h in [(False, 1.5e-9), (True, 1e-12)]:
    w1, w2 = 1.5e-6, 1.5e-6 + h
    om = lambda wl: 2 * np.pi * c0 / wl
    vg = (om(w1) - om(w2)) / (beta(w1, exact) - beta(w2, exact))
    print(f"{'exact b(V), dλ→0' if exact else 'approx. b(V), dλ = 0.1%':<26s}: "
          f"b = {fl.LP_b(fl.V_number(a,w1,n1,n2),0,1) if exact else fl.b_approx(fl.V_number(a,w1,n1,n2)):.5f}, "
          f"v_g = {vg:.5e} m/s, τ_g(1 km) = {1e3/vg*1e6:.4f} µs")
```

## Mode field diameter (slides 53–56)

The LP$_{01}$ field is very close to a Gaussian $E\propto\exp(-r^2/w^2)$. The MFD is $2w$. Because the
intensity is Gaussian, the fraction of power inside $r<w$ is $1-e^{-2}\approx 86\,\%$, just like a
Gaussian beam (Chapter 1).
